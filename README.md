# AssetTrack – Asset Management System

AssetTrack is a full-stack web application designed to simplify and centralize organizational asset management.

## Technologies Used
- Frontend: React.js
- Backend: Java, Spring Boot
- Database: MySQL
- API: RESTful APIs

## Key Features
- Add and manage assets
- View all available assets
- Track asset information
- Manage asset assignments
- Handle exceptions and validation
- Frontend and backend integration

## Project Structure
- Backend – Spring Boot REST API application
- Frontend – React.js user interface

## Objective
To provide a centralized platform for managing organizational assets efficiently and reducing manual tracking.
